# Phase 6A — завершённый Benchmark Dataset Generator

## Пользовательский сценарий

1. Откройте `/admin/`.
2. Перейдите во вкладку **Testing**.
3. Выберите загруженную книгу.
4. Укажите число Positive и Negative вопросов.
5. Нажмите **Сгенерировать набор**.
6. Следите за прогрессом: генерация идёт в фоне партиями.
7. После завершения набор автоматически откроется карточками.
8. Используйте фильтры Positive / Negative / Отклонённые.
9. При необходимости скачайте CSV или JSON.

## Что исправлено относительно первой версии

- генерация выполняется партиями, а не одним огромным запросом;
- отклонённые вопросы заменяются следующими попытками;
- есть ограничение числа попыток, поэтому процесс не зависает бесконечно;
- запрос запускается как background job, UI опрашивает статус;
- виден прогресс и текущая стадия;
- Positive проверяется по конкретному chunk;
- Negative дополнительно проверяется LLM-судьёй по наиболее близким фрагментам;
- тематическое совпадение больше не считается автоматически наличием ответа;
- набор имеет статус `complete` или `partial`;
- UI показывает вопросы карточками, ответы, страницы, evidence и причины отклонения;
- доступны поиск, фильтры, CSV и JSON export.

## Настройки

```env
BENCHMARK_GENERATOR_MODEL=gpt-4.1-mini
BENCHMARK_BATCH_SIZE=10
BENCHMARK_MAX_ATTEMPTS=8
```

## Критерий complete

Набор получает `status: complete`, только если принято ровно запрошенное число Positive и Negative вопросов. Если лимит попыток исчерпан, набор сохраняется как `partial`, а интерфейс прямо показывает это состояние.

## Ограничение проверки

Автоматические тесты и startup smoke пройдены. Реальный прогон через OpenAI требует действующего `OPENAI_API_KEY` и оплачиваемого API-счёта.

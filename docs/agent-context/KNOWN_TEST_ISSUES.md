# Known Test Issues

This document records confirmed pre-existing test and environment problems for `wineMD-widget`.

Agents must verify that a failure matches this record and that the current diff does not touch the affected area before treating it as pre-existing.

## Current known issues

No repository-specific issue has been confirmed and recorded yet.

Do not copy known failures from the main `wine-ai` repository into this file unless the same failure is independently reproduced here.

## Adding an issue

For every issue record, include:

- exact test name or command;
- exact symptom;
- verified cause;
- commit or date confirmed;
- conditions under which it may be treated as pre-existing;
- owner or follow-up issue, when available.

A failure may be listed here only after it has been reproduced on the unchanged base branch or otherwise proven unrelated to the current diff.

Do not add a failure merely because it is inconvenient, slow, or difficult to investigate.
Do not report a zero-assertion test as meaningful green coverage.

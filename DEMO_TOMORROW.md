# Быстрый запуск полного голосового демо

## 1. Проверьте `.env`

```env
OPENAI_API_KEY=sk-...
STT_MODEL=gpt-4o-mini-transcribe
ANSWER_MODEL=gpt-4.1-mini
TTS_MODEL=gpt-4o-mini-tts
TTS_VOICE=marin
```

Загруженная книга уже находится в `data/documents/runtime`.

## 2. Освободите порт 3000

Ошибка `EADDRINUSE` означает, что сервер уже запущен или порт занят.

Сначала попробуйте открыть:

`http://localhost:3000/demo.html`

Если страница не относится к текущему проекту, в PowerShell выполните:

```powershell
npx kill-port 3000
```

## 3. Запустите

```powershell
npm install
npm test
npm start
```

## 4. Покажите работу

1. Откройте `http://localhost:3000/demo.html` в Chrome или Edge.
2. Нажмите кнопку виджета справа внизу.
3. Удерживайте кнопку микрофона.
4. Задайте вопрос по загруженной книге.
5. Отпустите кнопку.
6. Виджет автоматически выполнит всю цепочку: STT → поиск по книге → ответ → TTS.

Первый запрос может занять дольше последующих. Разрешите браузеру доступ к микрофону.
